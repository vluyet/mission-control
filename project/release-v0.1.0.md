# Mission Control v0.1.0

First private release.

## Highlights

- Empty launch-ready workspace instead of demo data
- Core workspace, project, and task product flows
- Human and agent member model
- Comments, activity, watchers, attachments, and execution logs
- Scoped agent credentials and API contract export
- Manage Workspace admin hub with workspace assets
- OpenClaw instance registration and launch-safe agent sync
- Versioned install and update scripts

## Operational notes

- Production deployment uses `docker-compose.prod.yml`
- Install with `scripts/install.sh`
- Update with `scripts/update.sh`
- This release is tagged as `v0.1.0`
